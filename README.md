# ワールド

10km×10km の世界。北の半分は陸（平原・小高い山・川）、南の半分は海（沖ほど深く最大 100m）で、海の向こうに新しい大陸があります。まん中のはじめの 1km（ヤシの島・岩の小島・丘の島・砂浜の小島、潜水艦がくぐれるトンネルの島）はそのまま。近くだけ地形を作って描き、500m より遠くはだんだん霞みます（サーバーの負担は変わりません）。ログインなしで、みんなで歩いたり、小型車を運転したり、glTF（.glb）を置いたりできます。

- 画面：`index.html` 1 ファイル（Three.js 0.160）
- 通信：Supabase（位置とひとことは Realtime、置いた物は `props` テーブルと `props` 保存場所）
- 公開：GitHub Pages

## はじめの設定（1 回だけ）

1. Supabase の「SQL Editor」に `supabase-setup.sql` を全部貼って「Run」
2. `index.html` の上のほうにある `WORLD_CONFIG` に、Supabase の **Project URL** と **anon public キー** を入れる
   （service_role キーは絶対に入れないこと）
3. GitHub のリポジトリの Settings → Pages で、Branch を `main`、フォルダを `/ (root)` にして Save

設定が空のままだと、ひとりで遊ぶだけになります。

## 決まりごと

- 置ける物は全部で 200 個まで、1 個 10MB・45 万三角形まで（10MB にするには **`supabase-update-13.sql` を1回実行**）
- URL を知っている人なら誰でも置いたり片付けたりできます（ログインなし）
- 乗り物：自動車（タイヤ 2・3・4・6 個）、船・潜水艦（ほかの人も相乗りできる）、航空機
- glTF で置いた乗り物は、置いた本人だけが運転できる。☰ →「自分が出した物」の「🔒自分だけ」を押すと「👥みんな」になり、ほかの人も運転できる（もう一度押すと自分だけにもどる）。ほかの人が運転している船への相乗りは、どちらでもできる
- ワールドの 1 日は 1 時間（全員同じ時刻で昼と夜がくり返す）

- タイヤの名前は英語でもよい（`wheel_FR` `wheel_F` `wheel_MR` など）

- 速さはカスタムプロパティ `max_speed_kmh`（自動車 20〜90、船 10〜60、航空機 60〜300）
- 自動車の最高速度は、ボディのカスタムプロパティ `最高速度` でも決められる（Blender で「文字列」を選び、値に `120` のように km/h の数を入れる。10〜300km/h。ないときは 60km/h）。数の型でもよい。自動運転は一般道 70km/h・高速道路 100km/h までなのは同じ

### 自動車のライト（なくてもよい）

部品の名前を次のようにすると、その部品が光ります（どこに置いても、いくつあってもよい。`ヘッドライト.001` のような番号つきも同じ）。

| 名前（日本語） | 英語でもよい | 光り方 |
|---|---|---|
| `ヘッドライト` | `headlight` `head_lamp` | ライトをつけると白く光り、夜は前の道を照らす |
| `テールランプ` | `taillight` `tail_lamp` `rear_light` | ライトをつけると赤くうすく光り、ブレーキで明るくなる |
| `ブレーキランプ` | `brake_light` `stop_lamp` | ブレーキのときだけ赤く光る |
| `ウインカー左` `ウインカー右`（`左ウインカー` も可） | `turn_signal_L` `blinker_right` `indicator_l` など | オレンジに点滅する |

- ウインカーの左右は名前の「左」「右」（left / right / _L / _R）で決まる。名前に左右がないときは、置いてある場所（車の前を +Z にして +X 側が左）で決める
- ライトは「自動」なら、夜・雨・霧・雪のとき、自動運転と半自動運転のときに自動でつく。☰ →「車のライト」かキーボードの L で 自動 → オン → オフ を切りかえる
- 自動運転・半自動運転の操作パネルにも 💡（ライト）・⇦・⚠・⇨ のボタンが出る
- ウインカー：☰ →「車のライト」の ⇦ ウインカー／ウインカー ⇨／⚠ ハザード（キーボードは Z・X・H）。曲がり終わってハンドルがもどると自然に消える。自動運転・半自動運転では、交差点で曲がる手前、車線変更、高速道路の出口と合流、行き先で左へ寄るときに自動で出す
- みんなの車なら、ほかの人の画面でもライトとウインカーが光る

### 自動車の種類（2026-11-03）

☰ →「📦 glTF を置く」→ 乗り物 → 自動車 のあと、種類を選びます（そのあとタイヤの数）。画面の「📘 Blender でのつくり方」をひらくと、選んでいる種類の部品の名前とカスタムプロパティ、Blender での手順（名前・原点・カスタムプロパティ・書き出し）が出ます。

| 種類 | ボディ・タイヤのほかにいる部品 | できること |
|---|---|---|
| 乗用車・軽・スポーツ・ワゴン・バイク | なし | 人が乗るだけ。`座席_1`… を置くと相乗りできる |
| バス | なし（`座席_1`…16 席） | ほかの人が運転中に座席へ相乗り。座席がなければ車内にならべる。`定員` |
| トラック | `荷台` | 荷台の床 1㎡で 400kg（12t まで）。事業のトラックにつかえる |
| ダンプカー | `荷台` | 「荷台を上げる」（K）で荷台の後ろの下のふちを軸に前が上がる。土砂の量（㎥） |
| ミキサー車 | `ドラム` | ドラムが自分の縦の軸（Blender のローカル Z）で回る。「生コンを出す」（K）で逆回転。`容量`（㎥） |
| タンクローリー | `タンク` | `容量`（L、なければタンクの大きさから）、`積荷`（ガソリン・水・牛乳…） |
| 重機 | なし（`上部` `ブーム` `アーム` `バケット`／`ブレード`） | 「作業」（K）で旋回・腕が動く。関節は原点。最高 15km/h（指定なし） |
| トラクター・コンバイン | なし（`ロータリー` `リール`） | 「作業」（K）で回る。事業の農機 |

- 大きな種類（バス・トラック・ダンプ・ミキサー・タンクローリー・重機）は全長 12.5m・高さ 4.2m まで
- どの車でも `回転灯` `回転_1`… は「作業」で回る
- ボディのカスタムプロパティ `種類`（`ダンプ` など）があれば、その種類になる。選んだ種類は `props.kind` に保存し、ほかの人の画面でも同じ種類になる（`supabase-update-10.sql`）
- 動きはワールドが決める。.glb には部品の名前とカスタムプロパティだけを入れる

## 操作

- 右上の ☰ がメニュー：移動・地図・ひとこと・glTF を置く・なまえ（2 列のボタン）と「自分が出した物（数）」。自分が出した物は押すと一覧がひらく（自分が置いた物を消す）。潜水艦を操縦しているときだけ「船・潜水艦」と「コンピュータと対戦」が出る。時刻は左上の隅

- ☰ →「🚗 移動」：乗り物の一覧がひらく。はじめは「小型車」だけ（みんなに 1 台ずつ。最高 100km/h、高速道路も走れる。車体の色は自分の色）。glTF で置いた自分の乗り物（自動車・船・潜水艦・飛行機など）もここに出る。「乗る」を押すと、その乗り物を自分のところへ呼んで、そのまま運転席に乗る（船・潜水艦は近くの海に浮かべる）。小型車は「しまう」で片付けられる。がっち号はなくなった（2026-11-03）
- PC：↑（W）で向いている方へ前進、↓（S）で下がる、←→（A D）で向きを変える。マウスでドラッグすると見回せる（歩く向きとは別）。ホイールで近く／遠く（最大 120m）
- スマホ：左側をなぞった方向へ歩く（カメラから見た向き）。右側をなぞって見回す。2 本指でつまむとズーム
- 潜水艦に乗っているあいだは右上に地図（レーダー）が出る（押すと「近く 160m」と「全体 500m」を切りかえ）。船と潜水艦の速さはノット（kt）

## 潜水艦

- 潜水艦・イージス艦は回頭がゆっくり（前の 1/3）で、加速もゆっくり（前の 1/2）
- **音声の報告**（潜水艦）：聞こえている音だけを声で知らせる。「魚雷接近、右舷前方、方位○、距離○」（向きは 前方・右舷前方・右舷・右舷後方・後方・左舷後方・左舷・左舷前方）（見つけたときと 100m 近づくごと）、敵が装填したときの「注水音、方位○、距離○」（ソナーで聞こえる距離）。近づく魚雷があるとソナー音が鳴り、近いほど短く速くなる（ポーーン…ポン、ポン…ポ、ポ、ポ）。「☰ → 音声の報告」でオン・オフ（オンにすると試しにソナー音が 1 回鳴る）。声は端末にある日本語の男性の声を使い、なければ低い声にする。スマホは画面にさわると音が出るようになる（音量とマナーモードも確認）
- **シーキャット**：みんなに 1 隻ずつ配られる潜水艦。海に入って（泳ぐ・潜る）「☰ → シーキャット（潜水艦）を出す」で目の前に出る。ほかの人にも見え、対戦できる。沈んでも、もう一度出せば新しい 1 隻が出る（前のものは片付く）
- 機関停止（速力 0）にすると惰性で進み、そのあいだは無音。速いほど遠くまで進む（20 ノットから約 100m）。速力をマイナスにするとスクリューを逆に回して短い距離（約 35m）で止まる
- ソナーが音を聞けるのは半径 1500m。800m までは必ず聞こえ、そこから 100m ごとに聞こえる確率が下がる（800〜900m 80%、900〜1000m 70%、1000〜1100m 60%、1100〜1200m 50%、1200〜1300m 40%、1300〜1400m 30%、1400〜1500m 20%）。聞こえるかどうかは 10 秒ごとに決め直す。相手が 5 ノット以下なら 300m まで近づかないと聞こえない
- 船・潜水艦に乗っているあいだ、カメラは艦の後ろへ戻らない。横や斜めから見たまま走れる

- 潜水艦に乗っているあいだ、画面に出るのは操艦パネルとレーダーだけ（イージス艦は主砲・CIWS・目標解除のボタンも）。潜望鏡・ライト・救出・ひとこと・降りるは ☰ メニューの中

- 操縦は指示で行う（左下の操艦パネル、「－」でたためる）
  - 角度・速力・深度は、10 の位と 1 の位の ▲▼ で決める（10 の位は 100 を超えて 110、120… と増やせる）
  - 角度は決めただけでは回らない。「面舵」（右）か「取舵」（左）を押すと、その角度だけ回る。回っている途中でもう一度押すと止まる。例：10 の位 ▲×2、1 の位 ▼×3 で 17°、面舵で右へ 17° 回る
  - 「針路」を押すと、角度を方位（000〜360°、北が 000°）として、近いほうから回ってその方位を向く
  - 速力と深度は、決めるとすぐ加速・減速、潜航・浮上を始める
  - 「逆進」でスクリューを逆に回す（急ブレーキ・後進。最高は最高速力の 4 割）。もう一度押すと前進にもどる。「機関停止」で速力 0。「ピンガー」も操艦パネルにある
  - PC は ←→ で向きを少しずつ変える（旋回の指示は取り消し）、↑↓ 速力、Space／C 深度
- 方位は北（地図の上）が 000°、東が 090°。上の表示に、いまの方位・海底の深さ・HP が出る
- 圧壊深度：HP 15 なら 80m まで平気。HP が 1 減るごとに 6m 浅くなる（HP 10 なら 50m）。それより深いと 10 秒ごとに HP が減る（安全な深さから 0〜10m 深いと -2、10〜20m は -4、そのあとも 10m ごとに 2 ずつ増える）。HP 0 で圧壊・沈没。上の表示に「安全 ○m」、操艦パネルに警告が出る
- HP は最大 15。最高速力は HP に比例（満タンで 30 ノット）。魚雷の直撃で -7、近くの爆発で 50m 以内 -5・50〜100m -3・100〜150m -1（自分の魚雷でも）。HP 0 で沈没し、3 分で消える
- 魚雷の深度が相手の潜水艦の深度と ±5m 以内なら当たり（横の位置は艦体に重なったとき）
- 魚雷が潜水艦の船体に 30° 以下の浅い角度で当たると、爆発せずに跳ね返る（鏡のように、入った角度と同じ角度で出る）
- レーダー：自分の潜水艦が中央（艦首が上）で、方位を変えるとまわりが回る。半径は大きく映したときの「近く／遠く」で 100m〜1500m（潜水艦はふだん 300m・最大 1500m、イージス艦は最大 500m）。地形が透けて見える。音を出している相手は方位・距離・深度つきで映る（大きく映したとき）。タップで拡大、「閉じる」で戻る
- 魚雷は艦首の向きへ撃つ。目標を選んで撃つときも、目標が艦首の前 ±90° にいないと撃てない（警告が出るので艦首を向ける）。まっすぐ進むと陸地・海底・世界の端に当たるときも警告が出て撃たない（6 秒以内にもう一度「発射」を押すと、そのまま撃つ）。コンピュータも同じ。発射管は 4 門。「装填」を 1 回押すごとに 1 門ずつ、1 番から順に装填する（1 門 25 秒。4 回続けて押すと 4 番まで 100 秒）。装填ずみの門があれば、ほかの門の装填中でも撃てる。種類は装填のときではなく、撃つ直前に「弾頭／誘導／デコイ」から選ぶ（深度・距離も撃つときの値。どちらも ▲▼ で決める。スマホは「設定」で出る）。PC は B で装填、G で発射
- レーダーを大きくして、音の印（敵の潜水艦・デコイ）をタップすると目標になる（もう一度タップで解除）。目標がレーダーに映っていれば、発射のときにその方位へ魚雷を撃つ（デコイはいつも艦首の向き）。目標を選ぶと、そのときの目標の深度と距離が「魚雷の深度」「爆発する距離」に入る（魚雷タブ・弾頭・設定を開いたときも。あとで ▲▼ で変えられる）。「更新」を押すと、その瞬間の目標の方位・距離・深度で入れ直す。映っていなければ艦首の向きに撃つ。誰も乗っていない停泊中の船・潜水艦（イージス艦も）は灰色の四角でいつも映り、目標に選べる。音が消えた敵は「さっきまで居た点」（水色の点線の輪）として残り、選んで撃てる。また音がすると消える。相手が降りた・いなくなったとき、90 秒たったときも消える（デコイは点を残さない）。人が操縦している船・イージス艦もスクリュー音が聞こえ、潜水艦と同じように映って選べる。撃った魚雷は敵が動いても追わない（誘導魚雷は音を追う）
- 残弾は潜水艦ごとに 弾頭 20・誘導 10・デコイ 10
  - 安全距離：弾頭魚雷・誘導魚雷は、目標（選んでいなければ撃つ向き ±45° の近くの相手）が 300m より近いと撃てず、警告が出る。デコイはいつでも撃てる
  - 弾頭魚雷：60 ノット。「爆発する距離」（100・10・1 の位の ▲▼、20〜1200m）を進むと爆発（有効射程 1200m）
  - 誘導魚雷：50 ノット。前方 ±80°・300m 以内の音（動いている・装填中・撃った直後の潜水艦、デコイ）を追い、深さも合わせる。音が消えたらまっすぐ進む。潜水艦とデコイの音が両方聞こえると見失って蛇行する。自分の潜水艦とデコイ以外の魚雷には反応しない。当たったときだけ爆発し、800m で燃料が切れて沈む（有効射程 800m）
  - デコイ：25 ノット。20 秒で消える（決まり）。爆発しない
- 音のレーダー：ほかの人の潜水艦は、動いているとき・装填中・撃ってから 2 秒だけ地図に映り、地図の下に「ここから見た方位と深度」が出る。弾頭魚雷と誘導魚雷はいつも赤丸で映る。デコイは潜水艦と同じ印・同じ音に見える（デコイは撃っても発射音がせず、水面に泡の筋も残さないので、止まった潜水艦から撃つと、印が動き出したように見える）
- 地図に出るほかの人の点（目で見える位置）は、潜水艦が深度 5m 以上なら出ない（潜望鏡が水の上でも）
- ピンガー（PC は N）：打つと 5 秒間、ほかの潜水艦の位置が全部レーダーに映る（地図の下に「反響」として方位と深度）。同じ 5 秒間、打った自分も相手のレーダーに映り、相手の画面の真ん中に「ピンガーが打たれました」が 1.5 秒点滅する
- 魚雷（弾頭・誘導）が爆発すると、50m 以内のほかの魚雷も巻き込まれて誘爆する（デコイは消える）
- 魚雷（弾頭・誘導）が爆発してから 5 秒間は、だれの音も聞こえない（動いてもレーダーに映らない）
- 潜っているほかの人の潜水艦は見えない（浮上すると見える。潜望鏡だけ水の上なら潜望鏡が見えるが、深度 10m 以上では潜望鏡も見えない。自分も水中で 20m 以内なら見える）
- 水の中は透き通っていて、自分の潜水艦のまわりはよく見える。遠くほど段階的に青く暗くなる（深いほど少し暗い）

- 羽根もの：台ごとに V に入る確率がちがう（1/120・1/75・1/50・1/36・1/26 の 5 段階）。店・台番号・日本時間の日付で決まるので、同じ日ならみんな同じで、毎日入れかわる。釘の位置も少しずつちがう

### デジパチ「P 蒼天ブレイカー」（11 番台から上）

- 大当たり確率：通常 1/319.7、ラッシュ中 1/99.4

## 使える建物（.glb の作り方）

「glTF を置く」で「建物」を選ぶと、中に入れる建物になる。形そのものが床と壁になる（上を向いた面は歩ける床、立っている面は通れない壁）。

- 1 = 1 m。原点は地面の中心。入口（正面）は +Z 向き
- 置くとき：建物が自分の前に出て、歩くとついてくる。⟲ ⟳ で正面の向きを 15° ずつ回し（方角が出る）、「ここに置く」。黄色の枠の地面は平らにならされ、まわり 5 m でなだらかにつながる。15 m 以内に道路があれば、いちばん近い道路の高さにそろえる（山の上など道路から遠い所は、その場の地面の平均）。建物のいちばん下が地面にのる
- 片づけ（消す）は置いた人だけ：☰ の「自分が出した物」から
- **建物**：壁・床・階段・屋根は 1 つのパーツでよい。壁と床は 10〜20 cm の厚みをつける（ソリッド化）。階段は 1 段 40 cm まで、坂は 35° まで。ドア口は幅 80 cm・高さ 2 m 以上
- **ドア_1, ドア_2 …**：1 枚ずつ別パーツ。厚み 3〜5 cm。原点を蝶番に置く。E で 90° 開く（開ける人から遠ざかる向き）。カスタムプロパティ `開き方` = `横`（ドア本体でも中の形でもよい）か、名前を「引き戸_1」にすると引き戸になる。引き戸は向きを変えず、原点のある側へ横にすべるだけ（壁にめり込むときは、モデルでドアを少し室内側にずらす）。開いたドアはドア口の前（外からも）で閉められる。となりあう 2 枚はいっしょに開く。開け閉めはみんなに共有
- **ライト_1 …**：光る照明器具。夜に自動で点く。カスタムプロパティ `色`（例 `#ffd18a`）と `明るさ`（0.2〜3）は入れなくてもよい。本当に周りを照らすのは近くの 4 つまで（スマホは 2 つ）
- **ガラス**：窓。透ける（当たり判定はある）
- **スイッチ**：E でその建物のライトを点ける・消す（みんなに共有）。建物の中（屋根の下）ならどこでも「へやのライトを点ける」ボタンが出る。ライトのパーツがない建物は、中にいる人の頭の上が明るくなる
- **イス_1 …**：E で座る。前は +Z。動くと立つ
- **看板 …**（名前が 看板・sign・ネオン で始まる部品）：チカチカ点滅する。ほかの部品でも、カスタムプロパティ `点滅` を入れると点滅する（数字を入れるとその秒数で 1 回。例 `点滅 = 0.5`）。夜はもっと明るい
- **お店**：建物のカスタムプロパティ `用途` に「店」が入っていると、ライトはいつも点いていて、お客は消せない（`ライト = いつも` でも同じ）。ドアは自動ドアで、近づくと開き、だれもそばにいなくなって 3 秒で閉まる
- **BGM**：建物にカスタムプロパティ `BGM`（または `音楽`）で、ワールドに入っている曲の名前を書くと、建物の中（屋根の下）で流れる。出ると小さくなって止まる。いまある曲は `パチンコ`（sounds/pachinko.mp3）。`用途` に「パチンコ」があれば何もしなくても流れる
- **ドアがひとりでに閉まる**：ドアか建物にカスタムプロパティ `閉まる = 秒数`（例 `閉まる = 3`）。そういうドアは近づくと自動で開く
- 建物の「中」（一人称になるところ）は、屋根があって、まわり 4 方向のうち 3 方向以上に壁があるところ。入口のひさしの下はまだ外
- 建物の中（屋根の下）では一人称の視点になる。ドラッグで見回すと体もそちらを向く
- 建物の `名前` と `用途`（家・店・駅など）をカスタムプロパティに入れておくと、あとで使える
- カスタムプロパティ：Blender のオブジェクトプロパティ →「カスタムプロパティ」→「＋ 新規」。書き出すときに「含む」の「カスタムプロパティ」にチェック
- 見本：project の world-prototype/sample-buildings/sample-house.glb（ドア・ライト 2 つ・ガラス・スイッチ・イス・屋上への階段）

☰ →「🏢 事業」（または 新聞・株の画面の「🏢 事業」タブ）で、事業者登録をして会社を作れます。

- **事業の形**：個人事業主（0P・税20%・5人まで）／合同会社（60,000P・税25%・30人まで・会社の口座は別）／株式会社（200,000P・増資で株を売ってお金を集める・配当・金利が少し安い）。あとから法人成りもできます。
- **街の会社と取り引き**：みなと銀行・はじめ信用金庫で融資 → みなと不動産で土地（約190か所。店用・畑用）を買う／借りる → はじめ建設（新しい会社）に建ててもらう（プレハブの店・小さな店・スーパー・飲食店・倉庫・アパート・畑）。
- **仕入れ**：はじめファーム（野菜）・なか海水産（魚）・はじめ牛乳・みなと水産加工と契約。値段はその日の市場の値段。不作・不漁の日は量がそろいません。
- **運ぶ**：ふだんははじめ運輸（1kg 8円＋1kmごと1.5円）。トラックは はじめ自動車（新しい会社）で買う／みなとリース（新しい会社）で借りる／自分の glTF のトラック（種類・トン数クラスごとに1台目は無料）。glTF は ボディ＋タイヤ4・6・8輪＋「荷台」。荷台の床 1㎡で 400kg 運べます（1トン車〜10トン車のクラスに分かれる）。あいているトラックは はじめ運輸の下うけで運送業になります。
- **もうけ方いろいろ**：自分の店・飲食店／店を持たずにみなとマート・PA・カレー屋・ベーカリー・水産加工に卸す／畑（ファームが引き取る）／運送業／アパートの家賃。
- **人が集まる効果**：遊園地・水族館・スーパーなどの近くの店はお客さんが多く、自分の店に来た人はまわりの会社のお店にも立ちよります（帳簿に「まわりへの経済効果」）。
- **人**：仕事をさがしている住人を雇います。求人の給料は自分で決め、高いとほかの仕事の人も来てくれます。下げるとやめる人が出ます。社長もはたらき手1人に数えます。
- **決算**：毎日0時（実際の40分ごと）。閉じていたあいだの日もまとめて決算します。税金・赤字のくりこし、お金が足りないときはつなぎ融資、それも無理なら倒産（個人事業主は手持ちのPで借金を返す）。
- お金の計算はこの端末でします（localStorage `world.biz`）。会社の名前・使っている土地・建物・きのうの売り上げは Supabase の `businesses`・`biz_lots` に書き、みんなの画面に出ます（**`supabase-update-7.sql` を1回実行**）。土地は早い者勝ちで、1つの土地は1社だけです。ほかの人の店は地図にオレンジで出て、前で「のぞく」と社長や売り上げが見えます。
- **自分の glTF の社屋**：自分の土地の上に「glTF を置く → 建物」で置いた建物を、店・飲食店・倉庫・アパートにできます。建設費は0円で、設備費（はじめ建設のデザインの15%×広さ）だけ。床が広いほどお客さんが入ります。
- **自動車販売店**（🚗 車の販売）：自分で作った glTF の車を、自分の店で**ほかのプレイヤー**に売ります。
  - 店は はじめ建設に **階数（1〜3階）・広さ（小さめ／ふつう／大きめ）・つくり（木造／鉄骨／鉄筋コンクリート）** を指定して建てるか、自分の glTF の建物を販売店にします（建設費が浮く）。建物の前の空いた所が展示場で、登録した車の実物が値札つきで並びます。車が展示場に入らないと登録できないので、土地は車より大きくします。
  - 車種の登録：「glTF を置く → 自動車」で置いた自分の車をえらび、種類（乗用車・軽・スポーツカー・ワゴン・トラック・バス・重機・トラクター・コンバイン・バイク）を決めます。輪の数・大きさ・最高速度と、Blender のカスタムプロパティ（いくつでも）がスペック表になります。登録に試作・型の費用 50万円。値段は自分で決めます。
  - 店に来たプレイヤーは「のぞく」で、スペック・値段を見て、**試乗（ゲームの3時間＝実際の7分半）**して、買えます。買った車は店の前に出て、買った人だけが運転できます。注文ごとに はじめ自動車が1台作り（製造代は売った店が払う）、代金はつぎの決算で店の売り上げに入ります（`car_sales`）。
- **農機・田んぼ**（🚜 農機）：トラクターがあると畑・田んぼのとれる量 ×1.25・人手が減る。コンバインがあると田んぼの米をとりこぼさない（ないと65%）。田んぼ（いなかの土地）は秋（9・10月）に米がとれ、みなとマート・カレー本舗・はじめファームに卸せます。
- **果樹園**（2026-11-03）：畑用の土地に「🍊 果樹園（みかん）」（冬にとれる）か「🍎 果樹園（もも・ぶどう・りんご）」（夏〜秋）。植えてから6日（ゲーム）で、とれる量がそろいます。果物は はじめファームからも仕入れられ、マート・PA・ベーカリー・ドーナツ・はじめ牛乳に卸せます。
- **加工工場**（🏭）：材料（果物・野菜・魚）を ジュース・ジャム・野菜ジュース・干物にします（1日 材料1500kg まで・人手4人）。作る物は上から順にえらびます。ほかの会社の加工を受けることもできます（加工代は自分で決める。自分の別会社はいつでも、「みんなに出す」とほかのプレイヤーも）。
- **会社をいくつも**：事業の画面の上の「＋ 会社をふやす」。会社ごとに お金・借金・税金・従業員は別。名前のボタンで切りかえ。
- **🔗 グループ・委託**：品物の流れを つくります。①自分のほかの会社へ送る（市場の値段で売り買い）②加工をたのむ（はじめ牛乳＝ジュース、ひろ野ベーカリー＝ジャム、みなと水産加工＝干物、自分の工場の会社、ほかのプレイヤーの工場）→ この会社にもどすか、自分のほかの会社（お店など）へ。とどくのはつぎの日。例：果樹園の会社 →（ジュースに加工）工場の会社 → お店の会社で売る。
- **運送をたのむ**（🚚）：自分のトラックで運びきれない分を、自分の運送会社・ほかのプレイヤーの運送会社（「みんなに出す」にした会社）・はじめ運輸に たのめます。運送料は運ぶ会社が決めます。
- ほかのプレイヤーの会社に たのんだ加工・運送の代金は Supabase の `biz_trades` で相手に届き、相手のつぎの決算で売り上げになります。会社の一覧は `businesses.grp`（**`supabase-update-11.sql` を1回実行**）。お金の計算は それぞれの端末でします（`world.bizs`）。
- **ほかのプレイヤーの会社に入る**：☰ → 事業 →「💼 ほかの人の会社ではたらく」で、募集している会社に入社できます（3社まで・自分の事業もそのままできる）。会社の持ち主は「🙋 プレイヤー社員」で 日給 と 利益の分配（その日の利益の○%を社員で分ける）を決めて募集します（1社10人まで・社員は人手の1人に数える）。給与は持ち主の決算のたびに `biz_trades`（kind `wage`）で届き、手持ちの P に入ります（1割は所得税）。だれがどの会社にいるかは `biz_members`（**`supabase-update-12.sql` を1回実行**）。
- **トラックで実際に運ぶ**（2026-11-03）：🚚 で自分の glTF のトラックごとに「🧑 自分で運転」か「🤖 自動（従業員）」をえらびます。
  - 🧑 自分で運転（ふだん）：トラックに乗って、仕入れ先（はじめファームなど）の前で止まると「📦 積む」、卸す先（みなとマートの店など）や自分の店の前で「📦 おろす」。おろした分だけ、その日の運送が自分のトラックになります（はじめ運輸に払わない）。運ばなかった日は はじめ運輸が運びます。
  - 🤖 自動：従業員がいるとえらべます（トラック1台に1人）。毎日7時ごろ（ゲーム）、トラックが 仕入れ先 → 卸す先 → もとの場所 と町の道を走ります（信号・前の車・人で止まる）。ほかのプレイヤーの画面でも走って見えます。配達中は乗れません。あいた時間は はじめ運輸の下うけ。トラックは道路から30m以内に置きます。
- **glTF 機材の2台目から登録料**（2026-11-03）：自分で作った glTF のトラック・ダンプ・トラクター・コンバインなどは、種類ごとに1台目は無料（トラック類は種類＋トン数クラスごと。2トン車の2台目は有料、はじめての4トン車は無料）。2台目からは登録料（同じクラスの新車の半額：1トン車45万・2トン車75万・4トン車160万・10トン車375万・トラクター120万・コンバイン240万）を1回はらいます。登録料をはらったトラックの整備・保険はそのクラスの新車と同じ。トラックは荷台の積める重さで 1トン（1000kgまで）・2トン・4トン・10トン に分かれます。販売店で買った車と、一度はらった車はかかりません。
